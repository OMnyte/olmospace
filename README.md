# olmospace

> **Personal Laboratory, Atelier & Research Chambers — Olmo Marchi**

`olmospace` racchiude l'ecosistema di progetti, esplorazioni e laboratori fondati e guidati da **Olmo Marchi**: dall'orologeria concettuale svizzera ai sistemi di produzione visiva con intelligenza artificiale, fino alla finanza quantitativa sistematica e ai mondi virtuali.

---

## 🏛️ Le Camere del Laboratorio (Chambers)

### 01. CRAVED — Independent Conceptual Horology
* **Sito Live:** [craved.ch](https://craved.ch)
* **Status:** Live & Operating
* **Focus:** Orologeria concettuale svizzera indipendente. Esplorazione del tempo vissuto attraverso estetica meccanica pura e filosofia tangibile.
* *«Time doesn’t tick. It flows.»*

### 02. MIRROR STUDIO — Creative Systems & AI Engine
* **Sito Live:** [mirrorstudio.it](https://mirrorstudio.it)
* **Status:** Live & Operating
* **Focus:** Studio di sistemi creativi, direzione artistica ed engine di produzione visiva potenziati da intelligenza artificiale per brand ad alto impatto (Reflect, Foundation, Operate).

### 03. QUANT LAB — Systematic Finance & Quantitative Modeling
* **Status:** Active Research Chamber
* **Focus:** Ricerca quantitativa, microstruttura dei mercati finanziari, algoritmi di breakout/volatilità (Donchian sweeps, analisi frattale della liquidità, MQL5 & Python backtesting pipelines).

### 04. AI LAB & EXPERIMENTS — Applied Intelligence & Cognitive Tooling
* **Status:** Experimental Lab
* **Focus:** Sviluppo di agenti autonomi multi-step, framework cognitivi (MCP), generative UI e micro-applicazioni software ad hoc.

### 05. ROBLOX VENTURES — Virtual Worlds & Metaverse Mechanics
* **Status:** World Building & Incubation
* **Focus:** Esperienze virtuali interattive, retention loop, economie digitali e sistemi di gioco su motore Luau.

## 🛠️ Stack Tecnologico

* **Framework:** [Next.js](https://nextjs.org/) (App Router, Turbopack)
* **Linguaggio:** [TypeScript](https://www.typescriptlang.org/)
* **Styling:** [Tailwind CSS v4](https://tailwindcss.com/)
* **Iconografia:** [Lucide Icons](https://lucide.dev/)
* **Tipografia:** Geist Sans & Geist Mono (Next Font)
* **Hosting / CI/CD:** [Vercel](https://vercel.com/)

---

## 🚀 Sviluppo Locale

```bash
# Installa le dipendenze
npm install

# Avvia il server di sviluppo
npm run dev

# Compila la build di produzione
npm run build
```
